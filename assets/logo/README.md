# Logo

Lilia's listing icon: a blue tile (`#0A76A4`, Lilia's primary colour) with a white bold serif L, set in Charter. The L is drawn as an outline, so the SVG needs no font.

| File | Size |
|---|---|
| `lilia-logo.svg` | any (scalable) |
| `lilia-logo-512.png` | 512 × 512 |
| `lilia-logo-256.png` | 256 × 256 |
| `lilia-logo-128.png` | 128 × 128 |
| `lilia-logo-64.png` | 64 × 64 |

The PNGs have transparent corners. `server.json` lists them under `icons`.
